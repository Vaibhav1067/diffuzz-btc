diffuzz-btc results
Runs Throughput Coverage Corpus Sighash Reproduce

Runs

Every case goes to each listed implementation with identical consensus flags; only accept or reject is compared. Unexplained counts disagreements without a documented allowlist entry, plus crashes and timeouts.

    Throughput

    Cases per second per adapter process, and per-case latency. One process per implementation per worker; the slowest implementation sets the aggregate rate.

    Coverage

    How each generator's cases split between agreed accepts and agreed rejects, and which output types they spend. A generator that only produces rejects is testing failure paths only.

    Corpus

    Bitcoin Core's own script and transaction vectors, replayed through every adapter before its answers are trusted. Abstained vectors hit a documented adapter limitation and count as neither pass nor fail.

      Sighash and decoding

      Legacy, BIP143 and BIP341 signature hashes and transaction decoding, checked against upstream expected digests and across implementations. An implementation without the operation abstains.

      Reproduce

      Every run is seeded; any case can be regenerated from its seed and index, and every divergence is saved as one self-contained JSON case.
